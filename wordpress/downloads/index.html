روش ایمپورت در وردپرس خودتان

  1. افزونه Elementor (نسخه رایگان) را نصب و فعال کنید.
  2. افزونه استایل: پیشخوان → افزونه‌ها → افزودن → بارگذاری افزونه → فایل nadia-elementor-site.zip → فعال‌سازی.
  3. قالب‌ها: پیشخوان → قالب‌ها → قالب‌های ذخیره‌شده → Import Templates → سه فایل JSON را انتخاب کنید.
  4. ساخت صفحه: برای هر قالب یک برگه بسازید و در ویرایشگر المنتور قالب را Insert کنید.
  5. تنظیمات → خواندن → صفحه اصلی: «خانه»؛ و تنظیمات → پیوندهای یکتا → «نام نوشته».
