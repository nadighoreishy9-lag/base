دانلود فایل‌های سایت المنتور

همه خروجی‌های این سایت از همین‌جا قابل دانلود است: کیت سراسری المنتور (رنگ‌ها و فونت‌های سراسری + صفحه تک‌صفحه‌ای)، بسته کامل با افزونه استایل، یا قالب صفحه به‌صورت جداگانه. محتوای صفحه‌ها ویجت بومی المنتور است، پس بعد از ایمپورت همه‌چیز از داخل ویرایشگر المنتور قابل تغییر است. چیدمان، رنگ‌ها، فاصله‌ها، حاشیه‌ها و تایپوگرافی همه با تنظیمات خود المنتور ساخته شده‌اند (Flexbox و Grid بومی المنتور)، پس هر بخش را می‌توانید مستقیم از ویرایشگر جابه‌جا و تغییر دهید. فایل nadia.css فقط چند موردی را دارد که المنتور کنترلشان را ندارد (فونت وزیرمتن، راست‌به‌چپ، افکت شیشه‌ای، هاله‌های تزئینی، نسبت تصویر) — یا با «ظاهر → سفارشی‌سازی → CSS افزودنی» (بدون نصب هیچ افزونه‌ای) یا با افزونه استایل (اختیاری)؛ یکی از این دو کافی است (توضیح پایین صفحه).

دانلود 01-home.json

روش ایمپورت در وردپرس خودتان

  1. افزونه Elementor (نسخه رایگان) را نصب و فعال کنید.
  2. استایل‌ها (یکی از این دو، فقط یکی لازم است):
    الف) بدون افزونه (پیشنهادی): فایل nadia.css را دانلود کنید و کل محتوایش را در «ظاهر → سفارشی‌سازی → CSS افزودنی» بچسبانید و انتشار بزنید. (استایل و فونت وزیرمتن هر دو داخل همین فایل هستند.)
    ب) با افزونه (اختیاری): پیشخوان → افزونه‌ها → افزودن → بارگذاری افزونه → فایل nadia-elementor-site.zip → فعال‌سازی.
    چرا؟ اگر استایل داخل خود صفحه باشد، وردپرس آن را پاک می‌کند و متن CSS به‌صورت متن خام روی صفحه می‌ماند (صفحه بدون استایل و به‌هم‌ریخته) — پس استایل باید از فایل جداگانه بارگذاری شود.
  3. کیت (پیشنهادی): پیشخوان → المنتور → Tools → Import/Export Kit → Import Kit → فایل nadia-elementor-kit.zip. رنگ‌ها و فونت سراسری تنظیم می‌شود و صفحه تک‌صفحه‌ای سایت ساخته می‌شود.
  4. یا قالب جداگانه: پیشخوان → قالب‌ها → قالب‌های ذخیره‌شده → Import Templates → فایل 01-home.json را انتخاب کنید و در ویرایشگر Insert کنید.
  5. تنظیمات → خواندن → صفحه اصلی: «خانه»؛ و تنظیمات → پیوندهای یکتا → «نام نوشته».
  6. تصاویر از دامنه طراحی لاوایل بارگذاری می‌شوند؛ برای جایگزینی، هر تصویر را در کتابخانه رسانه آپلود و در المنتور عوض کنید.
