# سایت وردپرسی نادیا قریشی — خروجی المنتور

این پوشه خروجی آماده نصب روی **وردپرس** است: سه قالب صفحه المنتور، یک افزونه سبک برای
استایل‌ها و تصاویر پروژه. همه متن‌ها، تصاویر، دکمه‌ها و آیکن‌ها **ویجت بومی المنتور** هستند،
پس بعد از نصب می‌توانید همه‌چیز را از داخل ویرایشگر المنتور تغییر دهید.

## داخل این پوشه چه چیزی هست؟

| مسیر | توضیح |
| --- | --- |
| `nadia-elementor-site.zip` | بسته آماده: افزونه + سه قالب + همین راهنما |
| `plugin/nadia-design/` | افزونه استایل (توکن‌های رنگ، افکت شیشه‌ای، فونت وزیرمتن، چیدمان واکنش‌گرا) |
| `elementor/01-home.json` | قالب صفحه «خانه» |
| `elementor/02-services.json` | قالب صفحه «خدمات» |
| `elementor/03-portfolio.json` | قالب صفحه «نمونه‌کارها» |
| `bin/` | اسکریپت‌های راه‌اندازی نمونه و اسکریپت ساخت همین قالب‌ها |

## پیش‌نیازها

- وردپرس ۶ به بالا (نسخه php ۸ ترجیحاً)
- افزونه **Elementor** نسخه رایگان
- قالب **Hello Elementor** (رایگان و پیشنهادی؛ هر قالب سبک دیگری هم کار می‌کند)
- در «تنظیمات → همگانی» زبان سایت را **فارسی** بگذارید تا جهت نوشتار و تاریخ درست شود.

> طراحی با نسخه **رایگان** المنتور ساخته شده است: هدر و فوتر داخل خود صفحه‌ها هستند و
> صفحه‌ها با قالب «Canvas» (بدون هدر/فوتر قالب) ذخیره شده‌اند. نیازی به Elementor Pro نیست.

## نصب در پنج مرحله

1. **افزونه استایل**: پیشخوان → افزونه‌ها → افزودن → بارگذاری افزونه →
   فایل `nadia-elementor-site.zip` یا پوشه `plugin/nadia-design` → فعال‌سازی.
2. **قالب‌ها**: پیشخوان → قالب‌ها → قالب‌های ذخیره‌شده → «Import Templates» →
   سه فایل `01-home.json`، `02-services.json`، `03-portfolio.json` را انتخاب کنید.
   (در المنتور: Templates → Saved Templates → Import)
3. **ساخت صفحه‌ها**: برای هر قالب یک برگه بسازید (عنوان‌ها: خانه، خدمات، نمونه‌کارها)،
   در ویرایشگر المنتور روی «افزودن قالب» بزنید و قالب مربوطه را درج (Insert) کنید.
4. **صفحه اصلی**: تنظیمات → خواندن → «یک برگه ثابت» → صفحه اصلی: «خانه».
5. **پیوندهای یکتا**: تنظیمات → پیوندهای یکتا → «نام نوشته» → ذخیره.

## ویرایش بعد از نصب

- **متن، تصویر، دکمه‌ها، آیکن‌ها**: همه ویجت المنتور هستند؛ روی هر المان کلیک کنید و
  مستقیم از پنل سمت چپ ویرایش کنید.
- **جایگزینی تصاویر**: از پوشه `plugin/nadia-design/assets/images/` تصاویر خودتان را در
  کتابخانه رسانه آپلود کنید و در ویجت تصویر، تصویر جدید را انتخاب کنید.
- **رنگ‌ها/فاصله‌ها/افکت‌ها**: فایل
  `wp-content/plugins/nadia-design/assets/nadia.css` — بالای فایل متغیرهای رنگ
  (`--nd-primary`، `--nd-bg` و …) قرار دارد؛ تغییر همان‌ها کل سایت را هماهنگ عوض می‌کند.
- **فونت**: وزیرمتن از Google Fonts بارگذاری می‌شود؛ برای میزبانی محلی فونت، فایل را در
  افزونه بگذارید و آدرس Google Fonts را در `nadia-design.php` جایگزین کنید.

## نکته‌های فنی

- **تصاویر و مسیرها**: قالب‌ها تصاویر را با مسیر
  `/wp-content/plugins/nadia-design/assets/images/...` می‌خوانند تا بعد از نصب بدون تنظیم
  اضافه درست نمایش داده شوند. اگر وردپرس را در یک زیرپوشه نصب کرده‌اید (مثلاً `/blog`)،
  آدرس تصاویر را در ویجت‌ها به آدرس کامل تغییر دهید.
- **آیکن‌ها**: از FontAwesome همراه المنتور استفاده شده (`fas fa-search` و …) و در نسخه‌های
  جدید المنتور به‌صورت SVG درون‌خطی رندر می‌شوند.
- **بازسازی قالب‌ها از کد**: اگر محتوا را در کد تغییر دادید، با
  `python3 bin/build-elementor.py elementor` فایل‌های JSON بازسازی می‌شوند.
- **تست محلی**: با `docker compose -f docker-compose.base44.yml up -d` یک وردپرس محلی
  (پورت ۳۰۰۰) بالا می‌آید و `bin/bootstrap.sh` سه صفحه را از همین قالب‌ها می‌سازد.

## انتشار روی دامنه خودتان

بعد از انجام پنج مرحله بالا، سایت روی دامنه شما آماده است. برای انتقال کامل یک سایت محلی
به هاست، از افزونه‌های مهاجرت (مثل All-in-One WP Migration) یا انتقال دیتابیس + پوشه
`wp-content` استفاده کنید. رمز مدیر وردپرس پیش‌فرض محیط توسعه محلی
(`WP_ADMIN_PASSWORD` در `docker-compose.base44.yml`) را قبل از انتشار عوض کنید.
